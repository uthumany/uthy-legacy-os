# How to Contribute

See the full CONTRIBUTING.md file in the GitHub repository for detailed instructions.

## Quick Guide

1. **Fork the repo** — github.com/uthumany/uthy-legacy-os
2. **Create a skill** — Add a folder under `skills/<phase>/<your-skill>/SKILL.md`
3. **Validate** — `python scripts/validate-skills.py`
4. **Open a PR** — Include validation output in the description

## Skill Requirements

- YAML frontmatter with `name`, `description`, `version`, `author`, `license`
- Sections: Overview, When to Use, Instructions, Common Pitfalls
- Verification checklist at the end
- 800-2000 words recommended
- Real frameworks and methods, not generic advice

For more detail, read the full CONTRIBUTING.md on GitHub.
