# Skill Catalog

Complete list of all 30 skills + 4 workflows in Uthy Legacy OS.

---

## 🔍 Discovery Phase

### customer-interviews
Plan and conduct customer discovery interviews. Use when exploring a problem space, validating assumptions, or talking to users for the first time.
- **Format**: Interview guides, Mom Test principles, synthesis methods
- **Frameworks**: The Mom Test, Continuous Discovery Habits
- **Templates**: Interview guide template included

### competitive-analysis
Deep-dive competitive positioning analysis. Use when entering a new market, positioning a product, or understanding the competitive landscape.
- **Format**: Competitive profiles, positioning maps, feature analysis
- **Frameworks**: Porter's Five Forces, SWOT, competitive positioning

### market-sizing
TAM/SAM/SOM estimation with top-down and bottom-up approaches.
- **Format**: Market size calculation, sensitivity analysis, assumption documentation
- **Frameworks**: TAM/SAM/SOM, bottom-up vs. top-down

### user-research
Synthesis of qualitative and quantitative user research.
- **Format**: Research plans, affinity mapping, thematic analysis
- **Frameworks**: Generative/Evaluative/Descriptive research

### opportunity-solution-tree
Map opportunities to potential solutions using Teresa Torres's framework.
- **Format**: Tree structure from outcome → opportunities → solutions → assumptions
- **Frameworks**: Teresa Torres OST

## 🎯 Problem Definition Phase

### problem-statement
Frame the customer problem with evidence before jumping to solutions.
- **Format**: Problem statement canvas with evidence
- **Frameworks**: Evidence-based problem framing

### jobs-to-be-done
Understand customer goals using the JTBD framework.
- **Format**: Job statements with functional/emotional/social dimensions
- **Frameworks**: JTBD, outcome-driven innovation

### proto-persona
Create hypothesis-driven personas before full research.
- **Format**: Proto-persona canvas with assumption tracking
- **Frameworks**: Lean persona creation

### problem-framing
Reframe problems to unlock better solutions.
- **Format**: Framing techniques and exercises
- **Frameworks**: Five Whys, Flip the Frame, Question Ladder

### elevator-pitch
One-sentence value propositions using Geoffrey Moore's format.
- **Format**: Moore template with variations
- **Frameworks**: Crossing the Chasm positioning

---

## 💡 Solution Exploration Phase

### solution-brainstorming
Structured ideation with constraints.
- **Format**: Divergent/convergent thinking sessions
- **Frameworks**: SCAMPER, Crazy 8s, Analogy Thinking

### hypothesis-prioritization
RICE, ICE, and value-effort quadrant prioritization.
- **Format**: Scoring matrices with transparent reasoning
- **Frameworks**: RICE, ICE, Value vs. Effort

### experiment-design
Design lightweight experiments using the PoL method.
- **Format**: Experiment cards with success criteria
- **Frameworks**: PoL (Proof of Learning), Lean Experimentation

### prototype-planning
Plan what to prototype and at what fidelity.
- **Format**: Fidelity selection guide, prototype test plans
- **Frameworks**: Paper → Wireframe → Interactive → High-fidelity → Live-code

### validation-interview
Test prototypes and concepts with customer interviews.
- **Format**: Concept testing, prototype testing, Wizard of Oz
- **Frameworks**: Continuous validation, concept testing

---

## 📝 PRDs & Stories Phase

### prd-writer
Write comprehensive Product Requirement Documents.
- **Format**: Full PRD template with problem, scope, requirements, success metrics
- **Frameworks**: PRD best practices, launch criteria

### user-story-writer
Write user stories with acceptance criteria.
- **Format**: "As a / I want / So that" with INVEST criteria
- **Frameworks**: Mike Cohn format, INVEST

### acceptance-criteria
Write clear, testable acceptance criteria.
- **Format**: Given/When/Then scenarios
- **Frameworks**: Gherkin, BDD

### epic-breakdown
Split large epics into deliverable stories.

### technical-spec-bridge
Translate PRDs for engineering audiences.
